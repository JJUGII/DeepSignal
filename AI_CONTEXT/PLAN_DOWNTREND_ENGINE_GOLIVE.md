# 기획서 ① — 하락장 반등 엔진 라이브화

작성: 2026-06-15 · 분석엔진 담당 · 대상: `deepsignal/crypto_trading/downtrend/`

---

## 1. 배경 / 현황

- 하락장 단타 엔진(레짐 판정 → 반등 셋업 → EV 게이트 → 검증)을 5-Phase로 **이미 구현 완료**(36 테스트 통과).
- 단, **라이브 미배선** — `DOWNTREND_ENGINE_ENABLED` 기본 off, 결정 함수(`decide_downtrend_buy`)만 존재.
- 설계 철학: "하락장엔 대부분 쉬고, 고확률 반등(capitulation/RS reclaim/VWAP reclaim)만 짧게 먹기".
- ⚠️ 전제: 반등 셋업 3종은 **미검증 가설**. 이 프로젝트는 단기 호라이즌에서 엣지를 못 찾아온 이력이 있어 **대부분 탈락 가능성**을 깔고 간다. 그래서 검증 게이트가 안전핀.

## 2. 목표

> 하락장에서 (현물 한계상 숏 없이) **반등 롱으로 +EV를 내거나, 못 내면 정직하게 "현금이 답"으로 결론**. 어느 쪽이든 **검증 게이트 통과분만 실거래**.

## 3. 단계별 계획

| Phase | 내용 | 산출물 | 공수 |
|-------|------|--------|------|
| **G0 백테스트(선행)** | 과거 하락장 구간(2021-22, 2024 조정 등)에 셋업 3종 OOS 평가. 펀딩無·수수료·슬리피지 반영. **여기서 전멸하면 G1 진행 안 함** | `scripts/backtest_downtrend.py` + 결과 | 2~3일 |
| **G1 섀도 배선** | `decide_downtrend_buy`를 crypto auto_runner에 **관찰모드**로 연결(실주문 X). 레짐·셋업·EV·결정을 로그+가상체결로 기록 | 러너 훅 + `DOWNTREND_SHADOW_LOG.jsonl` | 1~2일 |
| **G2 데이터 수집** | 섀도로 **하락장 구간 200건+** 누적. 셋업별 실측 승률/손익 축적 | 셋업별 통계 DB | 수주~수개월(하락장 빈도 의존) |
| **G3 검증 판정** | `validate_strategy`로 게이트 판정: 200건·net+·PF≥1.2·MDD한도·연속손실≤5·shadow100 | 검증 리포트·`EDGE_GATE` 등재 | 1일 |
| **G4 카나리 라이브** | 통과 셋업만 **소액**(예 총자본 2~5%)으로 실거래. 보수 프로파일(스프레드0.15·포지션0.3·타임스톱3~5분) | 라이브 카나리 | — |
| **G5 확대** | 카나리 net+ 지속 시 점진 확대 | — | — |

## 4. 안전장치 (다중)

1. `DOWNTREND_ENGINE_ENABLED` 마스터 토글(기본 off)
2. `validate_strategy` 배포 게이트 — 미통과 셋업은 영구 섀도
3. 기존 EDGE_GATE + regime_gate(DM6) + TRADING_HALT 상속
4. 보수 프로파일(좁은 스프레드 → 하락장엔 사실상 대부분 무매매 = 손실회피)
5. 카나리 소액 → 확대 점진

## 5. 성공 기준

- **G0**: 백테스트에서 최소 1개 셋업이 수수료·슬리피지 후 PF≥1.2 & net+ (실패 시 프로젝트 보류, "현금이 답" 결론)
- **G3**: 섀도 200건+ 검증 게이트 통과
- **G4~5**: 카나리 net+ 지속, MDD 허용 내

## 6. 리스크

| 리스크 | 대응 |
|--------|------|
| 셋업 미검증 → 대부분 탈락 | G0 백테스트로 선제 거름. 탈락 시 깔끔히 포기 |
| 섀도 배선이 기존 L10 엔진과 충돌 | 관찰모드(실주문 X)로 시작, 결정만 로그 |
| 하락장 데이터 부족(데이터 쌓는 데 오래) | 백테스트(G0)로 사전 평가, 라이브는 천천히 |
| 라이브 전환 시 손실 | 카나리 소액 + 검증 게이트 |

## 7. 의사결정 필요 (사용자)

1. **G0 백테스트부터 시작할지** (권장 — 셋업이 통하는지부터 확인, 저비용·무위험)
2. 라이브 시 자본 배분(예 2~5%)
3. 섀도 vs 즉시 카나리 (권장: 섀도 먼저)

## 8. 한 줄 요약

> **코드는 끝났다. 남은 건 "이 반등 셋업이 진짜 돈이 되는가"를 데이터로 묻는 것.** G0 백테스트 → 섀도 200건 → 검증 통과분만 소액 라이브. **검증이 답을 정한다.**
